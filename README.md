# ATLANTIC OCEAN DATA EXPLORER

**Interactive exploration and visualization of Atlantic Ocean Argo data**

Web application for the exploration of **temperature and salinity variability** in the Atlantic Ocean as a function of time, geographic region and depth.

## Overview

The application provides an interactive visualization of aggregated **Argo oceanographic observations** for the Atlantic Ocean, including:

- Daily and monthly temporal resolution.
- Mean and median statistics.
- Standard deviation represented through point halos.
- 5° × 5° spatial grid and regional selection.
- Depth-based filtering.
- Interactive temperature and salinity scales.
- Light and dark visualization modes.

## Dataset

- **Data source:** Argo profiling floats
- **Study region:** Atlantic Ocean
- **Period:** 2017–2026
- **Spatial resolution:** 5° × 5°
- **Visualization records:** 6,080
- **Observations:** 1,156,790
- **Processed blocks:** 135

The aggregated dataset is stored in `data/data.js`.
